# Житнево Парк — Android TV

Полноэкранный мониторинг стоянки. Те же цифры, что у бегущей строки: панель Житнево и Дорожная сеть. Фон — камера Hikvision из локальной сети телевизора.

## Что на экране

- Шапка: знак Житнево Парк, часы (Москва), кнопка «Настройки».
- Первая строка, слева знак «Транспортные технологии»: сегодня, месяц, среднее, последняя машина и суммы.
- Вторая строка, слева знак «Дорожная сеть»: стоянка, душ, прачечная, отзыв, итоги. Тарифы как в строке: стоянка 350 ₽, душ и прачечная 180 ₽.
- Пока логины не введены, на экране образец цифр.
- Панель опрашивается раз в 3 минуты, Дорожная сеть — раз в 10 минут.
- Экран не гаснет.

## Камера Hikvision

В «Настройках»:

| Поле | Обычно |
| --- | --- |
| IP-адрес | адрес камеры в сети телевизора |
| HTTP-порт | 80, для HTTPS чаще 443 |
| RTSP-порт | 554 |
| Логин | admin |
| Канал | 1 |
| Субпоток | включён |

Два режима:

- **Снимок ISAPI** (по умолчанию). Каждые 4 секунды `GET /ISAPI/Streaming/channels/102/picture`. Вход Digest, если камера ответит 401 — запрос повторяется с подписью. Если у прошивки другой адрес снимка, пробуется ещё и канал без субпотока (`/channels/1/picture`).
- **Живой RTSP**. `rtsp://логин:пароль@IP:554/Streaming/Channels/102`, транспорт RTP поверх TCP (так стабильнее через Wi‑Fi телевизора). Плеер Android берёт H.264. Основной поток Hikvision часто H.265, его этот плеер не откроет — оставьте субпоток.

Телевизор и камера должны видеть друг друга по локальной сети. На камере нужны включённые ISAPI и RTSP и пользователь с правом просмотра. Затемнение фона — ползунок, по умолчанию 28%.

Сертификат панели, выписанный на IP, принимается. Дорожная сеть (`back.dornet.ru`) проверяется обычным образом. Пароли пишутся только в закрытые настройки приложения на приставке, в apk их нет.

## Сборка

Нужны Android Studio Narwhal 2025.1.3 или новее и JDK 17 (встроенный JDK студии подходит).

1. Распакуйте архив и откройте папку `ZhitnevoPark` (в ней лежит `settings.gradle.kts`, не вложенную папку).
2. Дождитесь Sync. Студия сама скачает Gradle 8.14.3 и SDK.
3. **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

Из терминала, если уже стоит Android SDK и `local.properties` с `sdk.dir`:

```
./gradlew assembleDebug
```

## Установка на телевизор

На приставке: настройки, об устройстве, семь нажатий по номеру сборки, затем «отладка по сети».

```
adb connect IP_ТЕЛЕВИЗОРА:5555
adb install -r app-debug.apk
```

Приложение в списке Android TV и в обычном лаунчере. Ориентация — альбомная.
